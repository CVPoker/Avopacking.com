# Imágenes / Images

Coloca aquí los archivos de imagen del sitio.

## Pendiente importante

- **`logo.png`** — Sube aquí el logo de AvoPack con ese nombre exacto.
  Mientras no exista, el sitio muestra automáticamente el nombre "AvoPack"
  como texto de respaldo en el encabezado.

## Fotos reales

Las secciones del sitio usan *placeholders* (recuadros con texto) donde irán
las fotos reales. Para reemplazarlos por fotos:

1. Sube tus fotos a esta carpeta (ej. `instalaciones.jpg`, `hass.jpg`, etc.).
2. En `index.html`, reemplaza cada
   `<div class="placeholder-img" ...>Foto: ...</div>`
   por `<img src="assets/tu-foto.jpg" alt="descripción" class="ph-photo">`.

Avísame y te dejo las fotos puestas en su lugar.
